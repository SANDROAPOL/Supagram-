# Supagram

Repositorio del frontend para el **Curso de Supabase de Supagram**. Una aplicación inspirada en Instagram construida con [Next.js](https://nextjs.org) y [Supabase](https://supabase.com) como backend.

## Tecnologías

- **Frontend:** Next.js
- **Backend:** Supabase (autenticación, base de datos, storage)

## Comenzar

La aplicación activa está en la raíz del repositorio. Desde `C:\Supagram`, instala
las dependencias e inicia el servidor:

```bash
npm ci
npm run dev
```

Abre [http://localhost:3000](http://localhost:3000) en tu navegador.

La copia antigua recuperada se conserva en `.local-archive/supabase-fundamentos-legacy`;
no la uses para iniciar la aplicación.
